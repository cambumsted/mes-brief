Workstream Timeline

A reasonable path from where we are today to an integrated marketing effectiveness solution — sequenced through the Crawl, Walk, Run framework with rough time estimates per workstream. Dates are illustrative; actual sequencing depends on resourcing and stakeholder alignment.

At a glance

Three phases, roughly 10–12 months end to end. Each phase delivers usable value on its own — we don't wait until "Run" to put something in leadership's hands.

Phase 1

Crawl — Define & Align

~6–8 weeks

Inventory what exists, agree on definitions, stand up a manual v1 of the unified view.

Phase 2

Walk — Centralize & Standardize

~3–4 months

Pilot a landing experience, operationalize the partnership grid, begin moment-level attribution.

Phase 3

Run — Integrate & Automate

~4–6 months

Integrated solution with drill-downs, automation where ROI justifies it, embedded in leadership rituals.

Phase 1 · Crawl — Define & Align

Get to a shared baseline

~6–8 weeks Goal: leadership can see one curated view of marketing performance, even if it's manually assembled.
WorkstreamDurationKey activities
Reports inventory 2–3 weeks Catalog existing reports across all four pillars. Identify owners, refresh cadence, and audience. Flag duplicates and gaps.
Metrics dictionary 3–4 weeks Define each KPI once: name, calculation, owner, source system. Resolve conflicts between channel-specific definitions.
Partnership grid template (v1) 2–3 weeks Standardize the cross-region partnership KPI grid. Agree on minimum comparable fields. Pressure-test with 2–3 partnerships.
Manual v1 unified view 3–4 weeks Curated deck or page that pulls headlines from each pillar. Refreshed monthly by hand. Proves the format before any tooling investment.
OCID & web-tracking deep dive 3–4 weeks Learn how OCIDs are generated today, who owns the request process, and how the current CMM structure maps to channels (email, paid media, partnerships). Document the existing taxonomy, the gaps, and where the model has drifted from how we actually market — the input for the Walk-phase taxonomy update.
Stakeholder & RACI Ongoing Confirm working group, owners per pillar, and decision rights. Lock the RACI before Walk starts.
Phase 1 exit: leadership has a single curated view they can reference in MBR, plus an agreed metrics dictionary and partnership grid template.

Phase 2 · Walk — Centralize & Standardize

Move from curated artifact to operational rhythm

~3–4 months Goal: a real landing surface, regional contributors filling the grid on cadence, first moment-level attribution.
WorkstreamDurationKey activities
Landing experience pilot 6–8 weeks Stand up a single page (SharePoint, hub, or lightweight site) that links to existing reports. No data integration yet — just the connective tissue.
Operationalize partnership grid 8–10 weeks Regional contributors (Asia, Americas, EMEA) update the grid on a defined cadence. Establish QA loop. First fully comparable cross-region view.
Cross-pillar review cadence Ongoing (start ~M4) Recurring working session that uses the unified view to drive a real decision each month. Tests whether the surface is actually decision-ready.
Campaign-to-moment attribution (v1) 8–12 weeks Tag outbound activities (email, paid, partnerships, GTM) to the moments they support — Back-to-School, Cyber Week, etc. Manual tagging is fine in v1.
ROI visibility gap-fix 4–6 weeks Identify channels with weak/missing ROI signal. Define the minimum proxy metric for each before Run-phase automation.
Phase 2 exit: a live landing experience used in a recurring leadership rhythm, with the partnership grid maintained by regional teams and a first pass at moment-level attribution.

Phase 3 · Run — Integrate & Automate

Make it the source of truth

~4–6 months Goal: integrated solution with drill-downs, selective automation, and a permanent place in leadership decision rituals.
WorkstreamDurationKey activities
Integrated solution build 3–5 months Move from links-and-curation to integrated drill-downs across the four pillars. Form follows requirements — dashboard, hub, or hybrid.
Automate moment attribution 6–8 weeks Replace manual tagging with system-side rules where the data supports it. Keep human review for ambiguous attribution.
Continuous trend view 4–6 weeks Replace MBR-only cadence with always-on headline trends. Alerting on directional shifts before they become surprises.
Embed in leadership rituals Ongoing Solution is referenced by name in MBR, planning, and investment decisions. Adoption — not output — becomes the success metric.
Selective automation Continuous Automate where the ROI of automation is justified. Leave manual processes manual where they're cheaper than the integration cost.
Phase 3 exit: the solution is leadership's first stop for marketing performance questions and is named as the source of truth in decision conversations.

Assumptions & caveats

  • Time estimates assume a small dedicated working group (not a full project team) with leadership air cover.
  • Phases overlap: Walk-phase work on the partnership grid begins while Crawl-phase definition work is still finalizing.
  • Run-phase build duration depends heavily on the technology choice — kept intentionally rough until that decision is made.
  • Dates assume no major reorg, no competing executive initiative pulling the same stakeholders, and access to existing reporting owners.
  • Each phase is designed to deliver standalone value — if priorities shift, we don't lose what's been built.
